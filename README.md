# SHXRM Studio

A paid, self-hosted Windows toolkit for IRL streaming, with a desktop control room and a mobile dashboard for your streaming PC.

**[Website](https://shxrmstudio.pages.dev) · [Setup guide](github-public/docs/SETUP.md) · [Windows releases](https://github.com/justshxrm-hash/SHXRM-Studio/releases)**

## Release status

**The public Windows download and purchase checkout are being prepared.** No buyer release is currently available in this repository.

When the Windows release is published, download its ZIP from **Releases**. A purchased activation key will be required to unlock the toolkit. **Code → Download ZIP** downloads this documentation repository.

## What it includes

- A desktop workspace and remote mobile controls.
- OBS streaming, recording, scene switching, and remote launch controls.
- Incoming camera and guest ingest management.
- Automatic low-bitrate and BRB scene protection during an active OBS broadcast.
- Private camera feed sharing for a friend's OBS.
- Connection controls, signal history, and Twitch, Kick, and YouTube multichat.

SHXRM runs on your own Windows PC. OBS, encoders, network access, streaming-platform accounts, and chat app registrations are configured and maintained by you. Hosted streaming servers and cellular bonding are separate.
